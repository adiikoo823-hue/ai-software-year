# Guyyaa 7: Madaallii Torban 1
1. HTML, CSS fi JavaScript garaagarummaan isaanii maali?
1 HTML jechuun Caasaa website ijaaruuf fayaada
FKN  Caasaa mana (darbii, foddaa fi balbala)
2 CSS jechuun bifa website bareechuuf fayaada
FKNBifa mana (halluu, miidhagina fi faaya)
3 Javascript jechuun website socho'a fi hojii rawwatu gochuuf fayyaada
FKN Hojii mana keessatti raawwatamu
2. students[0] fi students.length garaagarummaan isaanii maali?
1 STUDENT[0] jechuun elemanti jalqaba array student keessa jiruudha 
2 STUDENT.LENGTH jechuun elemaantoota array student meqaa akka ta'aan agarsiissa

3. const fi let garaagarummaan isaanii maali?
1 CONST jechuun wantaa tokko ergaa bareessine ykn rawwannee akka irraa deebi'nee jijjiirruu yoo hin barbaanne const fayaadamna
2 LET jechuun faallaa const yommuu ta'uu wantaa bareessine ykn rawwaanne irraa deebinee jijjiirru yoo barbaanne let fayaadamna
4. Flexbox keessatti justify-content maal hojjeta?
1 JUSTIFY-CONTENT jechuun wantoota keessa tokkon tokkoon akkata kallattii ijoo irraatti ittin qindeessinu murteessa
2 FILEXBOX jechuun wantoota garaa mirgaa fi bitaatti qindeessa
5. git add, git commit fi git push tokko tokkoon maal hojjetu?
1 GIT ADD jechuun wantoonni jijjiiramni isaanii commit keessatti akka hammatamu filata
2 GIT COMMIT jechuunjijjiirrama wantaa sanii keessa jiruu seenaa git keessaatti galmeessa
3 GIT PUSH jechuun commitwwan computer irraa jiraan gara remote repository ergaa

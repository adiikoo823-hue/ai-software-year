# Guyyaa 3
1. <img> maaliif fayyada? src fi alt maal jechuudha?
Deebii:<img> maaliif fayyada?

Website irratti suuraa agarsiisuuf.

src = faayilli suuraa eessa akka jiru, fakkeenyaaf src="Gemini_Generated_Image....jpg".
alt = suuraan yoo hin banamne, barruu ibsu. Namoota ija hin argineefis fayyada.

2. <form> keessatti <input> maaliif fayyada?
Deebii:<input> maaliif fayyada?

Fayyadamaan odeeffannoo galchuuf (maqaa, email). Fakkeenyaaf maqaa kee <input type="text"> keessatti barreessite.

3. event.preventDefault() maaliif barbaachise?
Deebii:event.preventDefault() maaliif barbaachise?

Form Send tuqiin, browser fuula ofumaan haaromsa (reload). Fuulli yoo haaromfame, ergaan keenya bada. preventDefault() haaromsuu sana dhaabsisa, kanaaf JavaScript ergaa kee agarsiisuu danda’a.

4. if ... else maal hojjeta?
Deebii:if ... else maal hojjeta?

Murtoo godha. Fakkeenya form kee:

Yoo maqaan duwwaa ta’e, “Please fill in...” jedha.
Yoo hin taane (else), “Thank you, Adinan!” jedha.

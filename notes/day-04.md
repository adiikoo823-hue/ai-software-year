# Guyyaa 4
1. display: flex maaliif fayyada?
Deebii:display: flex elementoota HTML keessaa tokko tokko sarara tokko irratti tarreessuuf fi bakka isaanii salphaatti to'achuuf fayyada. Akkasumas elementoota gidduutti iddoo uumuuf, walqixxeessuuf fi layout website ijaaruu keessatti gargaara.

2. justify-content fi align-items garaagarummaan isaanii maali?
Deebii:justify-content: Elementoota karaa inni ittiin qindaa'an (main axis) irratti qindeessa. Flex-direction durtii (row) keessatti kun kallattii dalgee (horizontal) dha.
align-items: Elementoota karaa main axis irratti hin taane (cross axis) irratti qindeessa. Flex-direction durtii (row) keessatti kun kallattii dhaabbataa (vertical) dha.

3. Navbar keessatti space-between maal hojjete?
Deebii:justify-content: space-between; elementoota Navbar keessa jiran gidduutti bakka duwwaa walqixa ta'e uuma. Elementiin jalqabaa gara bitaa, inni dhumaa gara mirgaa deema; elementoonni gidduu jiranis bakka isaanii irratti qindaa'u.
